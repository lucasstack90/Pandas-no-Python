# 🐼 Pandas Playground

Bem-vindo ao **Pandas Playground**!  
Um espaço para explorar, aprender e brincar com **Python** e a incrível biblioteca **Pandas**. Aqui você vai encontrar códigos práticos, exemplos e dicas para manipulação de dados de forma eficiente e divertida.

---

## ✨ Sobre o Projeto

Este repositório foi criado para:
- Testar funcionalidades da biblioteca **Pandas**.
- Guardar snippets úteis de manipulação de dados.
- Servir como referência rápida para projetos futuros em Python.
- Inspirar curiosidade e aprendizado na ciência de dados.

---

## 🛠 Tecnologias Utilizadas

- **Python 3.x**  
- **Pandas**  
- (Opcional) **NumPy**, **Matplotlib**, **Seaborn** para visualizações  

---

## 💡 Funcionalidades

- Leitura e escrita de arquivos CSV, Excel, JSON.  
- Limpeza e tratamento de dados.  
- Filtragem, agregação e estatísticas rápidas.  
- Exemplos de visualizações básicas com gráficos.  
- Transformações de colunas e manipulação de DataFrames.
